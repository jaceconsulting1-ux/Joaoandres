# Joao Calle Espinoza

**Hidrología · Geomática · Ciencia de datos ambientales**

[English](README.en.md) · [GitHub](https://github.com/Joaoandres) · [JACE Consulting](https://jaceconsultingec.com/)

Soy Joao Calle Espinoza. Mi trabajo conecta el análisis de datos hidrometeorológicos, la modelación de cuencas, la erosión hídrica y la información geoespacial para comprender procesos y apoyar decisiones sobre agua, suelo y territorio.

Integro programación en **R y Python**, análisis SIG y visualización interactiva. Este portafolio reúne investigación, desarrollo de herramientas y trabajo técnico vinculado a JACE Consulting y colaboraciones académicas. Cada ficha distingue su alcance, productos y limitaciones.

## Cómo trabajo

- Defino la pregunta, la escala espacial y temporal y los datos necesarios.
- Reviso unidades, fechas, calidad de observaciones y trazabilidad de transformaciones.
- Comparo métodos y evalúo resultados con criterios físicos y estadísticos.
- Distingo observaciones, estimaciones del modelo y escenarios exploratorios.
- Comunico resultados mediante código, mapas, gráficos y documentación reproducible.
